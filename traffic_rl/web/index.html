从交通路口开始，理解强化学习。

这是交通信号控制课程样例。智能体观察路况、选择放行方向，SUMO 模拟车辆运动，再返回新的状态和奖励。

  1. 问题不同车流下，怎样减少等待，同时避免某个方向长期得不到服务？
  2. 环境选择路口或环岛。车流由固定种子生成，便于复现。
  3. 学习按一次决策查看状态、请求动作、实际执行和奖励计算。
  4. 比较在同一道路、同一车流下切换策略，观察相同时刻；环岛提供自然让行基线。
  5. 合作队友可分别负责环境与车流、算法与奖励、实验分析、展示与报告，先确定统一评估条件。

训练时才更新模型参数；这里播放已完成的评估记录。规则策略同样可以帮助理解状态、动作和奖励。
