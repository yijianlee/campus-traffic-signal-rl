# 真实路口观测：尚未采集

此目录用于后续实地数据，当前没有真实交通记录。不要把 `data/generated` 中的车流标为实测。

先选择一个便于完整观察的有信号灯路口。记录名称或自定义编号、日期、天气、是否上下课高峰，以及是否存在大量行人和非机动车。

转向数若是按停止线通过车辆统计，应明确这一口径；拥堵时“通过数”不等于“到达需求”。如果只观察到了通过车辆，需要结合队列变化判断是否低估流量。

5 分钟到达量乘 12 可换算为该时段的小时当量，不能直接当成全天平均。建议首先各观察一个平峰和高峰窗口，检查差异，再决定是否增加日期。

## 接入当前模型前

1. 保存原始记录，不覆盖；另建整理后的参数文件。
2. 用部分观测估计需求和信号参数，保留另一时段检查模型是否能复现排队量级。
3. 如转弯、行人或非机动车占比明显，先扩展路网与冲突相位，不能直接将其全部当成机动车直行流量。
4. 参数表需注明数据来源、计数口径、时间范围与缺失值处理。

当前程序还没有实测数据自动导入器。确定具体路口和记录格式后再接入，避免预先假定真实道路结构。
