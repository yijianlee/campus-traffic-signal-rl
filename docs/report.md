# 课程报告框架

1. **问题与目标**：为什么研究信号控制，优化什么，采用哪些教学简化。
2. **环境与数据**：路口、综合车流、随机种子、训练与测试划分。
3. **方法**：14 维状态、4 个动作、奖励设计、DQN 与控制约束；解释经验回放和目标网络。
4. **实验设置**：软件版本、训练步数、学习率、网络结构、固定配时参数与测试时长。
5. **结果**：学习曲线、各测试种子结果、均值与波动；报告等待、排队和完成率。
6. **分析与改进**：DQN 在哪里有效或失效；进行一项奖励权重对照实验。
7. **局限与结论**：合成车流、单车道路口、训练充分性和现实适用范围。
