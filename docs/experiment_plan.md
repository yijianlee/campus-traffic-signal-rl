# 初步实验方案

## 选题与研究范围

暂定题目：**基于校园周边路口观测的强化学习信号灯控制仿真研究**。

当前阶段使用虚构路口，提交时如果仍未使用实测数据，题目应改为“面向校园周边交通场景的强化学习信号灯控制仿真研究”，避免暗示已做观测。

核心问题：车流方向和负荷变化时，DQN 相对于固定配时、排队优先规则，能否降低整体等待，且不显著增加少数方向的等待？

第一阶段完成单路口。转弯、行人、非机动车和多路口协调属于后续扩展，不一次性全部加入。

## 初始环境

| 参数 | 配置 |
|---|---|
| 路网 | 四进口十字路口；每方向一条直行进口车道 |
| 路段长度 | 每条约 300 米，路口几何会扣除部分车道长度 |
| 限速 | 11.11 m/s，约 40 km/h |
| 每回合 | 1,800 秒仿真时间；连续到达直至回合结束 |
| 决策间隔 | 5 秒 |
| 相位 | 动作 0：南北直行；动作 1：东西直行 |
| 约束 | 最小绿灯 10 秒、黄灯 3 秒、最大绿灯 60 秒 |
| 人工固定基线 | 目标绿灯 30 秒；决策网格下后续实际约 32 秒 |
| 传送车辆 | 禁用，避免自动移除拥堵车辆造成虚假改善 |
| 到达模型 | 各进口恒定强度的泊松过程；先生成显式车辆列表 |

车流均为自设参数，单位为每小时、每进口车辆数：

| 场景 | 北 | 南 | 东 | 西 |
|---|---:|---:|---:|---:|
| balanced | 300 | 300 | 300 | 300 |
| peak | 600 | 600 | 600 | 600 |
| tidal | 600 | 450 | 150 | 150 |

`peak` 只表示本项目中的较高流量，不代表已校准到饱和状态。后续可增加逐时变化的脉冲流量，但当前三个场景各自的到达强度在回合内恒定。

## 强化学习建模

状态是 13 维向量：2 维当前相位编码、1 维是否允许切换、4 维进口密度、4 维进口排队比例、1 维当前绿灯时长比例、1 维回合已用时间比例。四车道的具体排列由 SUMO 控制连接顺序确定；不能把它直接假定为 N/S/E/W。策略规则与指标通过车道名称查询。

奖励：

`r = -a × 总排队车辆数 - b × |南北排队数 - 东西排队数| - c × 本次是否实际切换`

初始设置 `a=1, b=0, c=0`，先完成基本排队优化。`b` 只是方向队列不均衡的代理量，不等价于个体等待公平性；是否改善公平性需要用分方向等待与尾部等待验证。先固定其余条件，再尝试 b=0.1、0.3 的消融。

选择标准 DQN、小型 64×64 MLP；初始训练 30,000 个决策步。每步对应 5 秒仿真，但训练步数不是实际运行秒数。SB3 的标准 DQN 不包含 Double/Dueling/PER，应按实际实现命名。

训练每回合重新生成车流，到达种子位于 `100000 + 训练种子 × 1000 + 回合序号`。默认训练种子 42；正式比较建议分别使用 42、43、44 训练。默认测试种子 101、102、103，与默认训练车流分开。

## 比较与评价口径

固定配时和排队优先规则是必须保留的基线，不只与随机动作比较。对每个“场景＋测试种子”，所有策略读取同一个车辆列表，并使用同一个 SUMO 种子。策略改变后车辆相互作用可能不同，因此并不保证每辆车经历完全相同的随机驾驶扰动。

| 指标 | 口径 |
|---|---|
| mean_stopped_wait_departed_s | 已入网车辆的累计停车等待均值，包含回合末尚未到达车辆；不是瞬时平均等待 |
| p95_stopped_wait_departed_s | 上述累计停车等待的 95% 分位数；未完成车辆仅记录到结束时刻 |
| mean_wait_plus_entry_delay_all_s | 对全部计划车辆求平均：已入网者为累计停车等待＋入网延迟；未入网者为结束时刻减计划到达时刻 |
| completed_vehicles | 已到达路线终点的车辆数，终点位于出口路段末端；不是精确的停止线通过数 |
| completion_rate | 完成车辆数 / 截止结束时刻计划进入的车辆数 |
| unfinished_vehicles | 已入网但尚未到达路线终点 |
| not_inserted_vehicles | 计划时间已到、尚未进入路网的车辆 |
| mean/max_queue_sampled | 每 5 秒采样的四条进口车道停车数之和；不是每秒精确积分或精确峰值 |
| 分方向等待＋入网延迟 | 按车辆入口方向分组，检查是否以牺牲小流量方向换取整体收益 |

“等待＋入网延迟”不是总旅行时间，也不是 SUMO 的 `timeLoss`。全部指标都只累计到评估结束；不能把它们当作所有车辆最终完整等待。正式研究可另加“停止生成新车后继续清空路网”的评估模式，当前尚未实现。

首版从空路网开始，没有独立暖机阶段。控制策略比较仍然同条件进行，但如果拟研究稳态交通，应后续加入统一暖机和更长评估时窗。

评估当前导出每次运行的原始结果，尚不自动计算跨训练种子的置信区间。正式报告应汇总均值与离散程度；调参使用验证集，最终测试另设未使用的种子。不得根据测试结果反复调参后仍称其为独立测试。

## 学期安排建议

| 阶段 | 任务 | 交付 |
|---|---|---|
| 第 1–2 周 | 熟悉 MDP、运行两种基线、确定真实路口候选 | 场景说明、基线结果 |
| 第 3–4 周 | 完成少量观测，检查仿真流量和排队是否合理 | 路口图、观测记录、参数依据 |
| 第 5–6 周 | DQN 训练、学习曲线和参数诊断 | 可重复的训练记录 |
| 第 7–8 周 | 高峰/潮汐泛化、多训练种子评估 | 完整对照结果 |
| 第 9–10 周 | 奖励公平性消融或需求扰动实验，择一深入 | 回答一个明确研究问题 |
| 第 11–12 周 | 整理报告、动画演示、局限性与复现实验 | 代码、报告、展示材料 |

这只是建议安排，需按课程实际周数与评分要求调整。实地观测是否为必选取决于老师要求；仿真主流程不依赖它。
