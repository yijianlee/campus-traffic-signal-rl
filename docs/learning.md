# 从一个决策理解强化学习

先在实验台选择道路和策略，进入学习模式，点击下一步。

| 概念 | 本项目中的含义 | 阅读位置 |
|---|---|---|
| 状态 s | 排队、密度、相位、绿灯年龄和回合进度 | `envs/intersection.py`、`envs/roads.py` |
| 动作 a | 请求放行方向 | `agents/baselines.py`、`agents/dqn.py` |
| 控制约束 | 最短/最长绿灯、黄灯、缺失进口检查 | `envs/` 的 step 方法 |
| 奖励 r | 停车、切换等惩罚之和 | step 返回的 reward_terms |
| 回合 | 从仿真开始到指定结束时间 | `experiments/training.py` |

状态来自决策前，奖励来自动作执行后。策略请求可能被最小绿灯限制暂缓，也可能由最大绿灯保护覆盖；学习面板分别展示请求与实际执行。

旧直行十字路口使用 **13 维状态、2 个动作**；转弯十字路口、丁字路口和环岛使用 **22 维状态、4 个动作**。两类模型不能互换。丁字路口的缺失进口通过掩码表示。

新道路奖励默认是全路网停车车辆数的负值，另加切换和无效动作惩罚；旧道路还支持南北/东西队列不均衡项，停车范围为进口。具体权重见 `configs/default.json`。不同奖励定义的分数不能直接比较。

环岛目前为单车道、逆时针、环内优先。入口信号控制进入流量；`yield` 基线持续开放入口。单车道不代表双向通行，增加环内车道属于另一项路网扩展。

建议学习顺序：固定策略单步观察 → 修改一项奖励权重 → 训练 DQN → 在独立种子上与规则基线比较。网页播放的是评估记录，只有训练命令会更新模型参数。
