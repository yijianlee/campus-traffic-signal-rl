# 学习与团队展示实验台

第一阶段提供交通演示、学习模式、项目导览和实验信息；不包含在线训练、双屏对比和双车道环岛。

## 生成页面

```powershell
# 四种道路、规则基线，不依赖本机已有模型
.\.venv\Scripts\python.exe -m traffic_rl show --layouts intersection crossroads tjunction roundabout --scenarios balanced peak surge --seconds 300

# 加入你已训练的模型；替换为实际路径
.\.venv\Scripts\python.exe -m traffic_rl show --layouts intersection crossroads tjunction roundabout --scenarios balanced peak surge --seconds 300 --model outputs/diversity_smoke/model.zip
```

`--layouts` 生成多道路演示包，与 `--layout` 互斥。单道路命令继续有效。只展示当前包中的实际记录：旧直行路口不支持 surge；多道路导出时，模型仅用于状态维度匹配的道路。因此混合训练的 22 维模型不会在旧 13 维路口中显示 DQN 选项。单道路导出仍会明确拒绝不匹配的模型。

导出需要先跑完实际仿真。每种道路/车流包含固定配时与排队优先，环岛另含自然让行，兼容模型另含 DQN。更多组合、更长回合会增加生成时间和文件大小。

生成后打开输出目录的 `index.html`；双击也可运行，不依赖服务器或网络。分享完整文件夹，至少保留 `index.html`、`style.css`、`app.js`、`renderer.js`、`recordings.js`；为复现实验还应保留根及各道路子目录的 `manifest.json`。旧版导出不会自动升级，需重新生成。

## 自学顺序

1. 打开“项目导览”，理解交通问题、SUMO 环境、控制策略与实验边界。
2. 在交通演示中选择道路、车流、策略。拖动画面平移，滚轮或按钮缩放，“复位”恢复初始视角。
3. 进入“学习模式”。初始状态不展示未来动作结果或奖励，点“下一步”完成一个 5 秒决策周期。
4. 对照三张卡片：决策前状态 → 请求动作与实际执行 → 执行后的奖励。展开向量可核对模型实际输入和下一状态；进口密度表为可解释物理量，不等于所有状态特征。
5. 找到最小绿灯暂缓、最长绿灯保护、黄灯/全红过渡。环岛自然让行显示入口持续开放，合流仍让行。
6. 切换策略，在相同时间查看其他策略；比较整段等待与完成率，而不是仅比较某个单步奖励。

学习面板始终展示**最近完成的决策**。例如时间轴在 12 秒，显示 5→10 秒的状态转移；画面中的车辆则位于 12 秒。点击“下一步”会跳至下一个决策终点，点击“上一步”跳至前一个边界。切换道路或车流暂停并回到 0 秒；切换策略保留时刻。若该组合无原策略记录，页面提示后切换至可用策略。

浅黄色圆圈标记最近完成动作所服务的进口，不代表车辆轨迹或神经网络注意力。自然让行会标记全部进口。

奖励分项直接由环境返回并记录，未改变原有奖励：旧环境统计进口停车和可配置的南北/东西不平衡惩罚，新环境统计全路网停车与无效动作惩罚，两者都支持切换惩罚。新环境不使用不平衡项，面板显示权重 0。奖励的分项之和必须等于记录的标量奖励。

模型在训练命令中更新参数；页面回放的是评估轨迹，**播放不会继续训练**。页面也不推测模型的内部思考，动作解释只描述控制器的可验证约束。

## 队友展示建议

用项目导览说明目标和角色：环境/车流、算法/奖励、实验/统计、展示/报告。展示一次被最小绿灯约束的动作，再展示自然让行和信号控制的差异。共同确定独立测试种子、回合长度、对照策略与评价口径。短程模型用于验证流程，不代表收敛结果。

“实验信息”显示道路、车流、种子、决策周期、物理步长、信号时长、状态维度、奖励统计范围和车流文件 SHA256。各子目录 manifest 保存配置、包版本和模型文件 SHA256，便于队友核对同一实验。

## 数据和验证

- `recordings.js` 格式版本 2：每种道路有实际车道几何，轨迹与决策记录分开存储。
- 每个决策记录包含起止时间、实际输入向量、下一向量、前后队列/密度/灯态、请求动作、实际动作、控制器原因、奖励分项和计算输入。
- 每个道路/策略子目录另外保存 `decisions.json`，可用 Python 单独分析。
- 静态路网使用缓存画布，动画仅重绘车辆、信号与动作标记；轨迹位置与角度在 SUMO 样本间插值。FPS 为本机浏览器绘制频率，不是仿真步频，也不是跨设备性能保证。
- 自动测试核对奖励分项、状态转移连续性、动作约束、多道路导出与原有回归；浏览器检查覆盖模式切换、单步、进度、场景与策略选择。
